# MS-1.1 — Mapping Assistant

Adds three practical features on top of MS-1:

1. **Auto Detect** for header row, first detail row, and OKD column suggestions.
2. **Mapping Templates** saved as JSON and automatically reused per workbook/sheet.
3. **Normalized Preview** showing the first output rows before export.

Auto Detect is intentionally a suggestion. The user remains responsible for reviewing the preview before saving the mapping.
