# MS-1 Acceptance Criteria

- [x] New standalone application.
- [x] Input workbook selected by the user.
- [x] Breakdown sheets selected by the user.
- [x] Mapping is stored separately per sheet during the session.
- [x] Output sheets are normalized independently.
- [x] WBS parents and children receive generated WBS codes.
- [x] Required OKD column names are present in every output sheet.
- [x] Original workbook is read-only from the user's perspective.
- [x] Output is written to Desktop as a new workbook.
- [x] Progress bar and current row message are visible.
- [x] Processing continues when one sheet fails.
- [x] LOG sheet is written.
