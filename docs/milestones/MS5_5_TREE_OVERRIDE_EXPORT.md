# MS-5.5 — Tree Override Export

The Draft WBS Tree is now the source of truth when the user chooses **Use this tree**.

- Shows Amount with two decimals.
- Any non-root row can be removed from the output tree.
- Rows can move up or down among siblings.
- Tree order, removed rows, WBS-3 and WBS-4 depth are used during Excel export.
- Deleting a heading promotes its children rather than silently deleting the full subtree.
